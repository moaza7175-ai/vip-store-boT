# 🧾 بوت تليجرام لإنشاء الفواتير، عروض الأسعار، الإيصالات والقوالب المخصصة

بوت تليجرام احترافي ومكتمل مصمم خصيصاً لإصدار قوالب رد سريعة ومستندات تجارية للمنتجات والمبيعات، ويدعم اللغة العربية بشكل كامل (RTL) مع خيارات تصدير متعددة: **PDF + صورة PNG + نص**.

---

## 🌟 المميزات الرئيسية

1. **📄 إنشاء الفواتير (Invoices):**
   - تسجيل بيانات العميل (الاسم، الهاتف).
   - إضافة عدد غير محدود من المنتجات (الاسم، الكمية، سعر الوحدة، الإجمالي لكل منتج).
   - حساب تلقائي للمجموع الفرعي، الضريبة (15%، 14%، مخصصة، أو بدون ضريبة)، والمجموع الكلي.
   - إضافة ملاحظات الفاتورة وتوليد رقم فرعي وتاريخ الإصدار.

2. **💰 عروض الأسعار (Quotations):**
   - تسجيل تفاصيل العميل والمنتجات والأسعار.
   - تحديد مدة الصلاحية (7، 15، 30 يوماً أو مخصصة).
   - كتابة الشروط والأحكام والملاحظات.

3. **🧾 إيصالات الاستلام (Receipts):**
   - إيصالات دفع واستلام احترافية.
   - تحديد المبلغ وطريقة الدفع (نقداً، تحويل بنكي، محفظة إلكترونية كـ فودافون كاش، بطاقة ائتمان).
   - توضيح وصف الدفعة وملاحظاتها.

4. **📋 قوالب مخصصة (Custom Templates):**
   - إمكانية إنشاء أي نوع قالب تريده بالحقول التي تحددها بنفسك (مثل: بوليصة شحن، استمارة حجز، سند قبض، إقرار استلام).
   - حفظ القوالب محلياً لكل مستخدم لاستخدامها في أي وقت بضغطة زر.
   - قوالب افتراضية جاهزة مدمجة مع البوت.

5. **⚡ تصدير متعدد:**
   - 📄 **ملف PDF جاهز للطباعة** بدعم كامل للغة العربية.
   - 🖼️ **صورة عالية الدقة PNG** للمشاركة الفورية عبر واتساب أو تليجرام.
   - 📝 **نص منسق** لنسخه مباشرة في الشات.
   - 🌟 خيار **تصدير الكل معاً** بضغطة واحدة.

## 📁 هيكل المشروع

```text
invoice-bot/
├── .env                  # ملف التوكن والإعدادات
├── .env.example          # نموذج الإعدادات
├── bot.py                # الكود البرمجي الرئيسي ومعالجات البوت
├── config.py             # الإعدادات ومسارات الخطوط والحالات
├── order_parser.py       # محلل ذكي لاستخراج بيانات الطلبات من أي نص أو رسالة
├── models.py             # نماذج البيانات (Invoice, Quote, Receipt, Template)
├── template_engine.py    # محرك توليد الـ PDF، الصور (Pillow)، والنصوص
├── requirements.txt      # المكتبات المطلوبة
├── run.bat               # ملف تشغيل سريع بنقرة واحدة
├── templates/
│   └── default_templates.json # القوالب الجاهزة
└── user_data/            # مجلد حفظ قوالب المستخدمين
```

## 📱 أوامر البوت على تليجرام:

| الأمر | الوظيفة |
| :--- | :--- |
| `إرسال رسالة مباشرة` | **⚡ الميزة الذكية:** انسخ أي رسالة طلب من واتساب/فيسبوك وأرسلها للبوت مباشرة وسيقوم بتحويلها لفاتورة فوراً! |
| `/start` | تشغيل البوت وفتح القائمة الرئيسية التفاعلية بالأزرار |
| `/quick` | شرح ودليل ميزة التحويل التلقائي للنصوص |
| `/invoice` | إنشاء فاتورة جديدة خطوة بخطوة |
| `/quote` | إنشاء عرض سعر مع فترة الصلاحية والشروط |
| `/receipt` | إنشاء إيصال استلام دفعة مالية |
| `/templates` | إدارة وإنشاء وتعبئة القوالب المخصصة |
| `/cancel` | إلغاء العملية الحالية والرجوع للقائمة |
| `/help` | عرض دليل الاستخدام |
